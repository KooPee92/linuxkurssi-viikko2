1. Linux distribution and version

I installed Ubuntu 26.04.1 LTS (Resolute Raccoon) on a virtual machine using CSC cPouta.

2. What is Nginx?

Nginx is a web server program. I installed it on my Ubuntu server so I can show my website on the internet. When someone opens my server's IP address in a browser, Nginx sends the web page to them.

3. Which commands did I use?

  • cat /etc/os-release
    Shows the Linux distribution and version.
  • sudo apt update
    Updates the package list.
  • sudo apt install nginx
    Installs the Nginx web server.
  • sudo systemctl status nginx
    Checks if Nginx is running.
  • sudo systemctl enable nginx
    Enables Nginx to start automatically after reboot.

4. Other Linux commands I used

I also used these commands while setting up my Linux server.

  • sudo apt upgrade
    Installs available system updates.
  • uname -r
    Shows the Linux kernel version.
  • sudo reboot
    Restarts the Linux server.
  • sudo systemctl is-enabled nginx
    Checks if Nginx starts automatically.
  • ls -l /var/www/html
    Shows the files in my website folder.
  • sudo nano /var/www/html/index.html
    Opens my website file for editing.
